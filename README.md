# Make _Make_ Great Again talk

A lightning talk on using [Make](https://www.gnu.org/software/make/) for
RSE South West 2025 in Bristol.

## Requirements

The presentation is designed to be run in a terminal. You will need the
following on your PATH:

 * bash
 * make
 * [bat](https://github.com/sharkdp/bat#installation)
